# AI Engineer Playbook

A growing, beginner-friendly knowledge base for understanding the foundations, engineering practices, and evaluation methods behind modern AI systems.

This repository documents concepts in my own words through:
- Intuitive explanations
- Analogies
- Mathematical foundations
- Worked examples
- Code implementations
- Testing strategies
- Interview explanations
- Connections between topics

## Purpose

The goal is not to collect definitions.

The goal is to develop enough understanding to:

1. Explain a concept simply.
2. Apply it in code.
3. Test whether it works.
4. Connect it to a larger system.
5. Discuss it confidently in an interview.

## Repository Principles

- Learn one topic at a time.
- Explain concepts in original words.
- Prefer understanding over memorization.
- Use generic, fictional, or publicly documented examples.
- Do not include proprietary business logic, credentials, customer information, private code, or confidential implementations.
- Cite external sources.
- Clearly separate personal explanations from quoted material.

## Doc Template

Topic docs under `02-computer-science/`, `03-software-engineering/`, `05-machine-learning/`, `06-ai-engineering/`, `07-ai-testing/`, and `08-system-design/` follow the same structure, so any single file is useful standalone without needing the rest of the repo as context:

```
# Topic
## Overview
## Why it exists
## Core Concepts
## Architecture
## Analogy
## Example
## Real-world Use Cases
## QA Perspective
## My Implementation
## Common Interview Questions
## References
```

Not every section will be filled on the first pass — `## My Implementation` in particular stays a placeholder until there's actually something built. Better to have the skeleton in place and let it fill in honestly over time than to fake completeness.

`01-mathematics/` and `04-network-science/` are foundational/theory-heavy and may not need every section (e.g. `QA Perspective` or `My Implementation` won't always apply) — use judgment per topic rather than forcing the full template.
